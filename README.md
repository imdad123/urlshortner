# URL Shortener

A URL shortener built with **React** and **Node.js**. This repository is the starting point for the project; implementation is planned.

## Planned features

- Create a short link from a valid destination URL
- Redirect visitors from a short link to its destination
- Validate URLs and handle unknown short links
- Provide a simple, responsive React interface
- Store link mappings in a database (to be selected during implementation)

## Planned technology

- **Frontend:** React
- **Backend:** Node.js (API framework to be selected)
- **Persistence:** Database to be selected

## Getting started

The application is not implemented yet, so there are no install or run commands at this stage. These instructions will be updated when the frontend and backend are added.
